# EcoyieldAI

## 🌱 AI-Powered Smart Farming Assistant

EcoyieldAI is an AI-driven web application that helps farmers optimize crop yield by analyzing **soil data, weather conditions, and market trends**. Using **machine learning**, the platform provides actionable insights on **optimal planting strategies** and yield prediction.

---

## 🚀 Features

✅ **AI Crop Prediction** – Recommends the best crops based on soil and weather conditions.  
✅ **Real-time Analytics** – Monitors weather patterns, soil quality, and market demand.  
✅ **Yield Forecasting** – Uses AI to predict expected crop yields.  
✅ **User-Friendly Dashboard** – Interactive charts and reports for easy decision-making.  
✅ **Cloud-Based Storage** – Saves farm data for future recommendations.  

---

## 🛠️ Tech Stack

**Frontend:** React, TailwindCSS  
**Backend:** Node.js, Express.js  
**AI Model:** Python (Scikit-learn, TensorFlow)  
**Database:** Firebase, PostgreSQL  
**Hosting:** AWS  

---

## 📦 Installation

Clone the repository:
```sh
git clone https://github.com/your-username/EcoyieldAI.git
cd EcoyieldAI
```

### 1️⃣ **Backend Setup**
```sh
cd backend
npm install
npm start
```

### 2️⃣ **Frontend Setup**
```sh
cd frontend
npm install
npm run dev
```

---

## 🖥️ Usage

1️⃣ Upload soil sample data (CSV or JSON format).  
2️⃣ AI analyzes the data and suggests optimal crops.  
3️⃣ View real-time insights on weather, soil, and market trends.  
4️⃣ Get yield predictions and plan farming decisions efficiently.  

---

## 🤖 AI Model Details

- **Crop Recommendation:** Trained on soil quality datasets using a Random Forest model.
- **Weather-Based Predictions:** Uses live weather API data for adaptive recommendations.
- **Market Trend Analysis:** Scrapes agricultural market data for price trends.
